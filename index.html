FAQ

How does PARKSMART know a spot is free?

An ultrasonic sensor on each spot reports whether a car is there. An AI camera at the entrance reads plates.

Why does the price change?

Prices rise when the lot is nearly full and fall when it is empty, which spreads drivers across lots.

Is my card number stored?

No. Only the last 4 digits are kept. The payment provider handles the rest.

What happens in winter?

Sensors are weatherproof and tested in cold conditions. If one fails, staff see a fault and the spot is hidden from booking.

The problem

Drivers waste fuel, add to traffic and raise CO₂ emissions while they circle for parking. PARKSMART combines smart sensors, AI cameras and a mobile app to cut search time by 40%.

Main project risks: harsh winters, sensor errors, low user interest and data leaks.

Cybersecurity

Unauthorized access

Strong hashed passwords, two-factor authentication and role-based access.

Secure payment

Trusted providers, secure gateways and HTTPS. Unneeded card data is never stored.

Secure communication

HTTPS with TLS for app, sensors and servers. VPN for administrators.

Database threats

Input validation against SQL injection, updates, backups, monitoring and regular security tests.
